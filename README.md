# CodeAlpha_Hangman
A console-based Hangman game built in Python using loops, conditions, and lists. Created as a CodeAlpha internship task. 
This project was created as part of my **CodeAlpha Python Programming Internship**.

---

## 🔹 Features
- Randomly selected word from a predefined list  
- Player guesses letters one by one  
- 5 lives system  
- Shows progress after each guess  
- Beginner-friendly Python logic

---

## 🔹 Technologies
- Python (Basic Concepts: loops, conditions, lists, string handling)  

---

## 🔹 How to Run
1. Make sure Python is installed on your system.  
2. Download the `hangman.py` file.  
3. Open terminal/command prompt and run:

```bash
python hangman.py
